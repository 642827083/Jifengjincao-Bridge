# 导入题目确认界面优化方案

2026-10-05。用户已确认并按本文方案实施；随后要求删除公式预览。当前测试包保留紧凑导入弹窗，仅显示文字摘要，不含公式预览库、字体或展开功能。下文已按最新范围调整，历史回放及验收结果见 [实施记录](implementation-validation.md)。

## 当前问题

截图底部按钮被裁切，对应当前 `.jfjc-sheet` 整体滚动、内部 `.jfjc-list` 再次滚动的双重滚动布局；外层使用内容盒宽高加 padding，最大高度也没有扣除外层留白。底部状态与动作没有固定区域。题干直接将 `stem_latex` 转为文本，因此预览露出公式源码；切割转义后的字符串也不适合承担公式预览。

## 推荐布局

采用一个紧凑的确认面板，头部、设置、底部操作固定，只有题目列表滚动。

1. 标题为“导入题目”，下方并列显示来源试卷和目标学习集，长名称省略但可以查看完整名称。目标学习集仍使用打开预览时捕获的学习集，切换学习集时沿用现有停止导入机制，不增加隐式改选。
2. 导入内容使用两个分段选项：“题目”“题目＋答案”，移至底部导入按钮左侧，沿用原生保存的最近选择。用户已确认后者仍包含答案和解析，仅缩短名称，不新增网页业务持久化。
3. “全选”“清空”放在来源与目标学习集的信息带最右侧，与目标学习集同一行；窄窗口来源单独一行，目标学习集与选择按钮保持同一行。移除列表顶部重复的总题数，只保留底部“已选 N / 总数 题”。行内用 20px 复选框、题号与简短题型、最多两行题干预览；选中行用浅蓝背景。保留原卷顺序，题型从已有题目字段读取，缺失时保留原章节名称，避免臆测分类。
4. 题干仅显示最多两行文字摘要，先截取原文前 180 个字符再转义，不执行 HTML、不渲染公式或图片、不提供展开功能。摘要与完整导入数据分开，原始 Markdown/LaTeX 不因显示和截断而改变；图片仍由原有导入流程下载、转存到 MN。
5. 底部左侧显示“已选 N / 总数 题”，右侧依次放导入内容选项和“导入 N 题”，取消按钮已删除；未选择时导入按钮禁用。顶部 × 负责关闭，导入中点击时停止任务，原生结束反馈前保持控件锁定；保留已完成卡片，结束后提供结果和失败题重试。较长错误列表在独立结果区域滚动，不挤走动作按钮。

## 尺寸与响应式

- 横屏建议宽度 720px，上限为可用宽度减 32px；窄窗口左右各留 12px。不额外放大窗口。
- 使用 `box-sizing: border-box`；面板高度限制在实际 WebView 视口减上下安全间距，设 flex 纵向布局，列表 `min-height: 0; overflow-y: auto`，其余区域不收缩。
- 横屏默认面板高度约 520px；短窗口和键盘弹出时按实际可用视口缩小。短窗口压缩留白，信息带允许换行，底部始终在可视区域内。
- 窄窗口底栏分两行，第一行为题数和状态，第二行为内容选项和导入动作，保持可见并避免横向溢出。
- 右下角只保留“选题导入”，打开列表默认全选。旧单题和整卷内部调用保留兼容，不再提供对应可见按钮。

此前总复选框与半选状态仅制作了独立预览；2026-10-06 按用户最新选择保留两个文字按钮，移至目标学习集同一行最右侧，不增加总复选框。
