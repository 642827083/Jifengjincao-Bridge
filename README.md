# Jifengjincao Bridge

把 [bbkaoyan](https://bbkaoyan.cn/) 的题目导入当前 MarginNote 学习集。当前正式版本为 `1.0.4`，作者：乔木Joe。正式安装包为 `Jifengjincao Bridge-v1.0.4.mnaddon`；下载见 [GitHub Release](https://github.com/642827083/Jifengjincao-Bridge/releases/tag/v1.0.4)。社区介绍 Markdown 保留在本地。

1.0.4 新增脑图手写上传、按当前题号自动查找来源卡片，以及“附加卡片内容”和可保存的“附加文字”；卡片图片排在手写或剪贴板图片之前。数学一、二、三导入层级区分“历年真题”和“模拟卷”。修复设置输入框创建失败导致的面板空白、裁切及缩放入口丢失，附加文字输入框调整为约三行高并支持框内滚动。

“设置 → 题卡工具”提供默认关闭的“自动折叠原题评论”，开启后对新导入及格式整理后的题卡生效；“已导入题卡管理”可批量折叠或展开当前学习集的原题评论。只处理插件生成的独立原题评论，保留正文、个人笔记与手写；缺少折叠接口时提示更新 MarginNote，题卡仍正常保存。

本版本将插件的“粘贴”和“上传手写”合并为“上传”。在“设置 → AI 工具 → 上传来源”选择“剪贴板”（默认）或“卡片手写”，选择由原生保存。卡片手写可用于解题、找题、普通对话和复盘等带上传控件的输入框：解题、复盘关联明确题号时，先按题卡 QUESTION 标记查当前学习集，无匹配再查其他学习集，无需选中卡片，也不改变脑图焦点；只上传对应卡片最后一条已保存的手写批注。没有对应题卡，或普通对话没有关联题号时，使用点击上传时单选的卡片并提示来源；未选、多选或所选卡片没有手写时提示原因。对应题卡没有手写或同题多卡无法唯一确定时停止，不借用其他选中卡片的手写。题号尚未加载时等待加载后再上传。保留草稿，由用户点击发送。普通图片评论不视为手写，不读取剪贴板，不向子卡寻找手写。切学习集、切题、来源卡片删除、移动或身份变化、修改最后一条手写、切换来源或关闭上传会停止尚未提交的操作；使用选中卡片备用来源时，改选也会停止。已经进入网站的附件需在原对话中检查。

“设置 → AI 工具 → 上传来源”还可选择“脑图手写”，上传来源题卡关联的已保存脑图笔迹，同样优先按题号找卡、找不到时使用单张选中卡片。不要求卡片有手写批注；没有脑图手写时明确提示，不借用卡片手写或其他卡片，也不自动保存正在编辑的画布。选择“卡片手写”仍只取最后一条批注，两种来源相互独立。

“设置 → AI 工具 → 附加卡片内容”（原“附带卡片首条内容”）默认关闭，对“剪贴板”“卡片手写”和“脑图手写”三种来源均可开启，已有开关状态保留。开启后，按当前题号优先找卡，无匹配或对话无题号时使用点击时单选卡片；从该卡读取首条图文，卡片文字追加到提问末尾，图片与所选上传内容一起添加为附件，图文混合时两者都带上。剪贴板模式不要求卡片有手写，剪贴板文字接在卡片首条文字后，图片仍优先于剪贴板自带的文字；内容在读取卡片前固定。无卡、多卡或来源不明确时提示原因；不附带标题、后续评论、内部身份注释或“查看原题”入口，不自动发送。正文为空时使用第一条评论，首条为空或不支持时明确提示，不跳到后面的评论。读取期间修改草稿、切换设置或来源内容变化时停止添加；图片上传完成后才追加文字，期间编辑草稿不会被覆盖，已进入网站的附件需自行检查。添加后总附件不超过 5 个，本次新增图片合计不超过 10 MiB。

“设置 → AI 工具 → 附加文字”默认关闭，在下面可换行的文字框自由填写内容，点击“保存”后由原生保存；关闭开关仍保留已保存文字，编辑中的未保存草稿不用于上传。开启后，每次上传都会在已有提问、卡片文字和所选上传内容后追加一次这段文字，三种上传来源均适用；可与“附加卡片内容”分别或同时开启，仍由用户手动发送。空内容或仅空白不追加；读取期间更改已保存文字、关闭开关、切题或编辑提问时停止添加。保存上限为 16384 个字符，保存失败保留原内容并提示。输入框采用插件内的本地页面，约三行高，支持段落、换行及框内滚动；保存成功后收起输入焦点，不将输入内容写入网页本地存储。保留面板初始化保护，网页、缩放及其他设置不受编辑器单独加载失败影响。

附带图片时，卡片首条图片排在前面，手写或剪贴板图片排在后面；首条包含多张图片时保留其原顺序。文件名分别使用“卡片图片”“脑图手写”“卡片手写”“剪贴板图片”，附加本次上传标识和序号，避免重名。

手写图片改由 MN 官方卡片媒体接口读取：先获取卡片内容分项，再按所选来源读取独立 PNG，不再解析 wrd 或近似重画笔迹。透明 PNG 上传前在原尺寸补白底。已在用户设备实际取得两条批注的 PNG（1024×608、1024×787）及一张脑图手写 PNG（513×418），均不含题干与原题链接。插件通过官方 AddonWebPanel 在设备内读取，点击上传会短暂显示读取浮层，页面就绪后取图并自动关闭；不保存电脑连接地址或令牌。脑图取图后复核媒体与原始图片，读取期间笔迹发生变化时提示重新上传。读取超时会显示停留阶段，缺少接口时提示更新 MN。请先退出手写编辑以保存笔迹；该功能需要支持官方媒体面板的 MN5 版本，其他版本会显示缺少接口提示。

## 安装与使用

1. 在 MarginNote 4.4.5 或更高版本中安装、启用 [MN Utils](https://mnaddon.craft.me/mnapi)。
2. 打开 `Jifengjincao Bridge-v1.0.4.mnaddon` 安装并启用插件。
3. 打开目标学习集，点击插件工具栏图标。
4. 在顶部“数学”页的内嵌网站打开一份试卷，按网站要求登录；可在“设置 → 题卡工具”调整“导入知识点”，默认开启。“查看原题”始终保留，原题链接开关已移除。
5. 点击网站顶部“AI 组件”左侧的“选题导入”，或切换顶部“导入”页选择试卷。按需取消勾选，确认学习集和底部导入内容，然后开始导入。

在“设置 → 题目工具”可调整“显示定位卡片”和“定位卡片方式”。试卷题号、题目详情与复盘的本题对话处显示“定位卡片”；默认“定位并聚焦”，可选择“仅定位”。点击后优先查找当前学习集，找不到再查其他学习集，多张匹配题卡会让你选择，成功后关闭插件面板。定位读取题卡所有评论中的内部身份，兼容新版第二条评论与旧版题干中的标记。

独立“导入”页按科目浏览试卷。同一科目、同一年只有一份真题时，直接点击“2026 年”即可查看题目；同年多份或缺少年份时保留完整试卷标题。模拟卷按“科目 → 年份 → 作者 · 系列 → 卷号”展示，例如“数学二 → 2027年 → 李艳芳 · 三套卷 → 卷一”，完整标题保留在悬停提示和右侧选卷标题中。作者优先读取网站提供方名称，缺失时兼容完整标题；无法识别时保留原文，不猜作者或卷号。这里只精简目录显示，导入后的试卷与题卡名称继续使用完整原名。

插件窗口参考大观园，使用 44 点高的导航栏，居中显示“数学／导入／设置”页签，右侧保留关闭按钮。“数学”显示原网站，切换设置后再返回保留浏览位置。设置页顶部固定胶囊导航，从左到右为“题目工具／题卡工具／AI 工具”，AI 工具紧挨题卡工具右侧，每次只显示当前分类，并在本次面板使用期间分别记住滚动位置；浅灰背景、白色圆角卡片及窄窗口下方控件布局保持一致，配置由原生保存。独立导入页读取目录或题目时显示“停止读取”，也可直接切换数学或设置以取消读取；返回保留目录、题目与勾选，需要更新时手动刷新。真正导入时显示“停止导入”，停止或完成前保留切页保护；空闲选题框会在进入设置时关闭。导航栏两侧空白处可自由拖动窗口并移出屏幕，右下角缩放时保持左上角位置；双击恢复默认位置与大小，关闭后重新打开会将面板恢复到屏幕内。网页内选题导入统一放在网站顶部 AI 组件左侧；独立导入页可直接选择试卷和题目。试卷封面收起时保持同排标题对齐；桌面展开第二排封面时同步增加同排高度。年份与卷号按钮等宽单行排列，空间不足时横向滑动。

页签使用与大观园相同的 14 号系统粗体，顶部选中项为蓝色文字和滑动下划线；设置分类通过白色胶囊滑块标识，连续切换从当前显示位置衔接，缺少动画接口时直接切换。切换设置分类会关闭选择弹层并停止旧分类的评论管理反馈。导入确认弹窗压缩来源与目标信息；底部在“导入 N 题”左侧选择“题目／题目＋答案”，后者仍包含答案与解析，仅缩短按钮名称。底部取消按钮已删除，顶部 × 负责关闭；导入中点击 × 停止任务，原生结束反馈前不会解锁或开始新导入。列表默认全选，空选禁用导入，选中行浅蓝，仅显示最多两行文字摘要，不渲染公式或图片、不提供展开预览。只有题目列表与结果区滚动，底部设置与导入按钮固定可见，窄窗口时底栏分两行。摘要截断不改动传给 MN 的完整 Markdown、LaTeX 和图片数据。安装包不包含公式预览库和字体，只保留实际加载的网页合并脚本。

题卡的第二条 Markdown 评论固定先显示“查看原题”，后面只保存 QUESTION 身份注释，不再写入 ORDER / SOURCE。链接使用 MN 插件入口，在当前 MN 窗口打开面板，有试卷来源时滚动到对应题目，没有试卷来源时打开题目详情。打开面板不会扫描或修改旧卡。需要整理时，点击“设置 → 题卡工具 → 修复题卡格式”，直接执行原有修复逻辑，包括为旧版关闭链接的题卡补齐入口，完成后显示结果。先保存完整正文和身份再清理旧位置，保留图片、用户评论、手写、子卡和标题，支持撤销及失败后重试。手动修改过链接、身份冲突或无法确认正文的题卡不自动整理。

选项优先读取网站已转换的公式字段；原始 `$ 公式 $` 去掉定界符内两侧空白，使其与 MN 行内公式格式一致。打开面板时也会修复已有插件题干、答案与解析中的这一边界问题，不重新下载正文，不修改独立用户评论、代码、图片引用或公式内容。修复可撤销；仍需在 MN 真机检查实际数学显示。

在网站复盘、AI 解题和 AI 找题对话的输入框操作栏，插件“上传”位于 Pro 右侧；没有 Pro 时放在网站文件上传入口后。来源为剪贴板时，文字插入光标处或替换选中文字，保留前后草稿；图片经过网站原有附件上传流程后出现在当前对话附件区。剪贴板同时包含图片和文字时优先添加图片。按钮不自动发送消息，也不写入 MN 题卡，只有主动点击时读取剪贴板。附件满额仍可粘贴文字；图片的上传权限、附件数量及大小沿用网站规则，上限为 10 MiB，过大的 PNG 尝试转 JPEG，仍超限时提示裁剪。忙碌或输入框只读时不可上传。文字传输期间改动草稿或替换输入框时停止插入，避免覆盖新内容；切题、切换对话、关闭面板或页面导航会停止后续传输，已经加入网站的内容需在原输入框或附件区检查。

设置 → AI 工具 → 显示上传默认开启，沿用旧版“显示粘贴”的开关状态。关闭后，所有 AI 对话输入框的插件“上传”按钮消失，各种来源均停止读取；重新开启恢复所选来源。开关由原生保存，网页重载和重新打开面板后继续生效。关闭时停止尚未提交的传输，保留已有草稿与附件。双击导航栏两侧空白处重置窗口时，默认大小为 980 × 680，超出学习窗口时自动缩小。

试卷页的“选题导入”显示整份试卷，默认全选，可只保留需要的题号。题目详情数据有来源试卷时按第一个来源试卷收集，没有来源时显示该题并放入对应科目的“单题收集”。

默认结构为 `Jifengjincao Bridge / 科目 / 历年真题或模拟卷 / 试卷 / 试卷名称 · 第 N 题 / 答案与解析`，数学一、二、三均按网站试卷类型分类，分类节点按需创建，AI 找题与题篮按每题来源试卷归类。已有试卷、分组及题卡保持原位置，继续导入复用原试卷，重复导入仍扫描旧分组查重；无来源试卷的“单题收集”和指定落点的“导入本题”保持原流程。试卷类型缺失时明确提示，不按标题猜测。新题卡标题使用原来源内容，例如“2014 年考研数学二真题 · 第 19 题”，正文不再追加“来源”行。第一条 Markdown 评论保存题干、题目图片、全部选项及按设置保留的知识点，不保存内部注释。第二条只保存原题入口及 QUESTION 题卡身份，不创建纯注释评论；补导题卡直接追加到父卡末尾，不调整已有卡片的位置，也不额外保存排序信息。历史关闭原题入口的设置不再生效。“导入知识点”仍独立保存，在打开选题框时固定本次设置。已有题卡的标题与来源正文不批量改写。题干保留 Markdown/LaTeX；图片下载并转存为 MN 媒体。答案与解析分别保存在同一子卡的两条 Markdown 评论中；子卡身份注释沿用原结构，放在答案末尾，只有解析时放在解析末尾。手动点击修复题卡格式时，会把旧子卡可明确识别的纯身份评论合并进正文，支持撤销。答案子卡默认隐藏在折叠的题卡分支中。

重复导入跳过已有题卡。选择“题目与答案解析”时，只补尚未保存的答案或解析，不更新已有题干、答案、用户评论或手写。网站数据不完整时显示未完成原因，并可重试未完成题目。停止导入保留已完成的卡片。

每道题使用一个撤销分组，整卷导入对应多次撤销。删卡或撤销后再次导入会检查实际卡片，不仅依赖历史映射。

“选题导入”统一显示在网站顶部“AI 组件”左侧，不再悬浮于网页右下角；没有可读题目时禁用。AI 找题只收集最新一轮结果中已经加载的匹配题，排除历史轮次、边界候选与内容暂不可用的题目。题篮详情与公开题篮也支持选题导入，收集当前页面已加载的题目。导入框默认全选，支持“题目／题目＋答案”，逐题保留原试卷与原题号，仍按原卷题卡结构建卡。切换对话或题篮、找题结果变化、题篮题目移除或排序后，旧请求停止，需重新打开选题框。

设置“题目工具”新增“显示导入本题”（默认关闭）与“导入本题位置”（默认子节点，可选同级节点）。开启后在试卷、题目详情、复盘、最新找题结果及题篮详情显示“导入本题”；AI 找题与题篮题号旁的定位入口显示为“定位题目”，仍定位已导入的 MN 题卡。题篮两项工具位于全局题号右侧，分别受已有显示开关控制。先在 MN 选中卡片，再点击“导入本题”，不弹选题框，仅导入题干、选项与题目图片，使用题卡工具中的知识点选项，保留原题入口及身份评论。子节点放到所选卡片下，同级节点插在所选卡片之后；读题期间改选卡片或设置不会改变本次落点。同一父卡下已有该题则跳过，其他父卡已有该题不阻止本次插入。单题操作不改变批量导入的内容选择。

## 真机验收

自动化测试使用模拟 MN 宿主，不能确认系统 WebView、MN Utils 安装版本和 MN 数学渲染器的实际行为。安装后依次检查：

- [试卷 237](https://bbkaoyan.cn/papers/237)：先导入第 1 题，检查题干、选项、答案和复杂公式。
- 导入第 4 / 第 19 题，断网并重启 MN 后查看解析图片。
- 整卷导入 22 题，检查原卷顺序，再导入一次，确认跳过已有题卡。
- 手工增加笔记，再补答案或重试，确认批注保留。
- 在数学与设置页间切换，检查网站浏览位置保留；关闭知识点开关并重新打开面板，确认设置保存，新题卡不含知识点行，再开启后导入另一道新题检查知识点恢复。检查新题卡标题包含试卷和题号、正文没有重复来源；重复导入不会重写旧卡片标题或笔记。
- 切换三个设置分类，检查胶囊导航固定、各分类分别恢复滚动位置、窄窗口末行可完整滚入视野；快速切换导航、拖动两侧空白区域、双击复位并调整窗口大小，检查按钮与手势互不干扰。
- 确认题卡工具中保留“导入知识点”，新题卡第一条包含完整题干和选项，第二条先显示“查看原题”再保存识别注释。打开已有题卡所属学习集的面板，先确认旧卡未变化，再手动点击“修复题卡格式”，检查手动执行、完成提示、旧注释整理、原题入口、去重、补答案与定位；撤销能恢复旧结构，用户自改链接和笔记保留。
- 导入时停止、切换网站页面或学习集，检查不会导入到错误位置。
- 使用实际账号检查一份有权限的模拟卷、登录过期及验证提示。
- 在 AI 找题页打开最新结果的“选题导入”，确认默认全选、原卷题号与图片保存；重新找题或切换对话，检查旧预览不能继续导入。
- 开启“显示导入本题”，在 MN 选中卡片，分别验证子节点与同级节点位置、同父重复跳过、另一父卡可再次导入，以及题号旁“定位题目”可以返回对应 MN 题卡。
- 从题卡点击“查看原题”，确认面板关闭时能重新打开，网页定位题目准确；在多个 MN 窗口中确认只打开当前窗口。旧卡片先手动点击“修复题卡格式”，确认链接更新后题干、图片、批注及评论顺序保留，撤销可恢复。
- 分别选择剪贴板、卡片手写和脑图手写并开启“附加卡片内容”，检查纯文字、纯图片和混合首条：复盘、解题及普通对话按题号优先或单选备用读取首条，卡片图片在前且文件名为“卡片图片”，上传内容在后，保留原提问且不发送。剪贴板文字也应附带首条，关闭开关恢复独立上传。读取期间改草稿或切题应停止添加，附件容量不足时不派发部分图片。
- “附加文字”输入两段内容并保存，开启后验证三种上传来源每次只追加一次，关闭后停止追加但保留保存内容；与附加卡片内容同时开启时顺序正确，不替换选中的提问、不自动发送。重新打开设置确认内容保存，窄窗口检查输入和保存操作可达。

不具备网站权限时插件会停止读取；会员内容不能依靠公开真题的测试结果认定可用。复杂数学宏与 HTML 图片可能需要针对样例进一步适配。

## 开发

```sh
npm ci
npm test
npm run check
npm run build
```

默认构建只更新测试包。`npm run build:release` 拒绝 `0.0.0` 和覆盖已有正式包，正式发布须遵循项目规范。构建生成 `src/web-dist/`，网页代码修改 `web/src/`，不要手改生成文件。`BBKaoyanLayout.js` 负责试卷目录布局，`BBKaoyanPage.js` 负责网页导入交互，`BBKaoyanReview.js` 负责各 AI 对话输入框的文字粘贴与图片附件。

源码职责：`BBKaoyanAdapter` 校验题目结构；`BBKaoyanFormat` 整理公式和图文；`BBKaoyanImport` 建卡、补答案与报告；`BBKaoyanTransport` 管理分块传输；`BBKaoyanImportStore` 原子持久化；`JifengjincaoNative` 封装已核实宿主能力；`JifengjincaoSettings` 管理原生设置页与导入配置；`WebPanelController` / `WebAddon` 提供窗口和生命周期。

导入记录在 MN 文稿目录的 `cn.marginnote.jifengjincao-bridge/imports.json`，包含最近 20 个任务和卡片映射，不保存密码、Cookie 或图片 Base64。损坏或不支持的记录文件会保留并提示错误。

目前 290 项自动化测试通过，覆盖页签切换、设置与窄屏布局、第二条原题链接及注释、旧卡迁移与失败恢复、历史关闭配置兼容、去重与补答案，以及定位卡片、多卡选择、跨学习集切换和定位网页校验。试卷 237 的 22 题数据回放通过；试卷 265 的 23 题格式回放及 27 个选项的公式边界修复检查通过。浏览器验证了横屏、竖屏、窄窗口、第二排展开布局、异步题目定位，以及复盘、解题、找题的粘贴入口与合成图片附件。粘贴测试覆盖 WebView 布尔返回值转换、完整网页脚本注入、延迟加载、满额与忙碌提示、切题和输入框替换；三种上传来源附加内容另覆盖图片顺序与命名、剪贴板纯文字和 JPEG、整批附件容量、Unicode 分块、受控草稿追加、内容变化及损坏数据拒绝。附加文字覆盖本地输入页及实际 iframe 桥接、独立开关、原生保存与失败恢复、长中文和换行、编辑器归属及保存途中修改保护、重复上传和窄屏输入区域；面板另覆盖控件构造期间同步布局、编辑器失败和半成品重建，检查数学页加载及缩放角。公式预览已按用户要求移除，文字摘要和完整原文传输分别验证。原生设置页目前由模拟宿主检查控件创建、布局和事件，需要 MN 真机验收实际显示。安装包已逐文件核对哈希与入口依赖。详见 [实施与验证记录](docs/implementation-validation.md)。

## 问 AI 外部入口（测试中）

接受 `jifengjincao-bridge?action=ask-ai&paper=<原卷ID>&question=<题目ID>`，从试卷题卡或单题卡进入 `/questions/<题目ID>` 的本题 AI 解题面板。沿用当前窗口及网站登录状态，不发送问题。原有 `action=open` 仍打开原题／试卷定位。需配合支持“问 AI”按钮的 Focus Switch。

网页顶部采用紧凑布局：Logo 缩小、搜索折叠为放大镜按钮，点击展开原站搜索框，Escape 或点击顶部外部收起；原输入、结果与搜索事件保留。选题导入、AI 组件、套卷、分类题库、题篮、文章/讨论、通知和账户保持可见，仅隐藏明确的交流群、售后群和群号信息，轮播中的赞助和其他通知保留。窄窗口按完整按钮换行，不将文字挤成竖排，也不收进额外的更多菜单。
