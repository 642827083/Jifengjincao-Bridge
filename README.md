# Jifengjincao Bridge

把 [bbkaoyan](https://bbkaoyan.cn/) 的题目导入当前 MarginNote 学习集。当前正式版本为 `1.0.2`，作者：乔木Joe。正式安装包为 `Jifengjincao Bridge-v1.0.2.mnaddon`；下载见 [GitHub Release](https://github.com/642827083/Jifengjincao-Bridge/releases/tag/v1.0.2)。社区介绍 Markdown 保留在本地。

## 安装与使用

1. 在 MarginNote 4.4.5 或更高版本中安装、启用 [MN Utils](https://mnaddon.craft.me/mnapi)。
2. 打开 `Jifengjincao Bridge-v1.0.2.mnaddon` 安装并启用插件。
3. 打开目标学习集，点击插件工具栏图标。
4. 在顶部“数学”页的内嵌网站打开一份试卷，按网站要求登录；可在“设置 → 题卡设置”调整“导入知识点”，默认开启。“查看原题”始终保留，原题链接开关已移除。
5. 点击网站顶部“AI 组件”左侧的“选题导入”，或切换顶部“导入”页选择试卷。按需取消勾选，确认学习集和底部导入内容，然后开始导入。

在“设置 → 题目工具”可调整“显示定位卡片”和“定位卡片方式”。试卷题号、题目详情与复盘的本题对话处显示“定位卡片”；默认“定位并聚焦”，可选择“仅定位”。点击后优先查找当前学习集，找不到再查其他学习集，多张匹配题卡会让你选择，成功后关闭插件面板。定位读取题卡所有评论中的内部身份，兼容新版第二条评论与旧版题干中的标记。

独立“导入”页按科目浏览试卷。同一科目、同一年只有一份真题时，直接点击“2026 年”即可查看题目；同年多份或缺少年份时保留完整试卷标题。模拟卷按“科目 → 年份 → 作者 · 系列 → 卷号”展示，例如“数学二 → 2027年 → 李艳芳 · 三套卷 → 卷一”，完整标题保留在悬停提示和右侧选卷标题中。作者优先读取网站提供方名称，缺失时兼容完整标题；无法识别时保留原文，不猜作者或卷号。这里只精简目录显示，导入后的试卷与题卡名称继续使用完整原名。

窗口使用一条 36 点高的导航栏，居中显示“数学／导入／设置”页签，右侧保留关闭按钮；浏览菜单、返回、题库、刷新入口及对应处理逻辑已删除。“数学”显示原网站，切换设置后再返回保留浏览位置。设置页参考大观园的浅灰背景与白色圆角分组，在“题卡设置”分组提供“导入知识点”开关，配置由原生保存。正在读取或导入时需先停止或等待完成再切换；空闲选题框会在进入设置时关闭。导航栏仍可拖动窗口，右下角可调整大小。网页内选题导入统一放在网站顶部 AI 组件左侧；独立导入页可直接选择试卷和题目。试卷封面收起时保持同排标题对齐；桌面展开第二排封面时同步增加同排高度。年份与卷号按钮等宽单行排列，空间不足时横向滑动。

页签使用与大观园相同的 14 号系统粗体，选中页签为浅灰圆角底与蓝色文字。导入确认弹窗压缩来源与目标信息；底部在“导入 N 题”左侧选择“题目／题目＋答案”，后者仍包含答案与解析，仅缩短按钮名称。底部取消按钮已删除，顶部 × 负责关闭；导入中点击 × 停止任务，原生结束反馈前不会解锁或开始新导入。列表默认全选，空选禁用导入，选中行浅蓝，仅显示最多两行文字摘要，不渲染公式或图片、不提供展开预览。只有题目列表与结果区滚动，底部设置与导入按钮固定可见，窄窗口时底栏分两行。摘要截断不改动传给 MN 的完整 Markdown、LaTeX 和图片数据。安装包不包含公式预览库和字体，只保留实际加载的网页合并脚本。

题卡的第二条 Markdown 评论固定先显示“查看原题”，后面保存 QUESTION / ORDER / SOURCE 注释。链接使用 MN 插件入口，在当前 MN 窗口打开面板，有试卷来源时滚动到对应题目，没有试卷来源时打开题目详情。在对应学习集打开一次插件面板，会将明确受管理的旧题卡整理为相同结构，包括旧版关闭链接的题卡。先保存完整正文和身份再清理旧位置，保留图片、用户评论、手写、子卡和标题，支持撤销及失败后重试。手动修改过链接、身份冲突或无法确认正文的题卡不自动整理。

选项优先读取网站已转换的公式字段；原始 `$ 公式 $` 去掉定界符内两侧空白，使其与 MN 行内公式格式一致。打开面板时也会修复已有插件题干、答案与解析中的这一边界问题，不重新下载正文，不修改独立用户评论、代码、图片引用或公式内容。修复可撤销；仍需在 MN 真机检查实际数学显示。

在网站复盘、AI 解题和 AI 找题对话的输入框操作栏，“上传”和“Pro”右侧显示“粘贴”；没有 Pro 时放在上传后。复制文字后点击按钮，会插入光标处或替换选中文字，保留前后草稿；复制图片后点击按钮，图片经过网站原有附件上传流程后出现在当前对话附件区。剪贴板同时包含图片和文字时优先添加图片。按钮不自动发送消息，也不写入 MN 题卡，只有主动点击时读取剪贴板。附件满额仍可粘贴文字；图片的上传权限、附件数量及大小沿用网站规则，上限为 10 MiB，过大的 PNG 尝试转 JPEG，仍超限时提示裁剪。忙碌或输入框只读时不可粘贴。文字传输期间改动草稿或替换输入框时停止插入，避免覆盖新内容；切题、切换对话、关闭面板或页面导航会停止后续传输，已经加入网站的内容需在原输入框或附件区检查。

设置 → AI 工具 → 显示粘贴默认开启。关闭后，所有 AI 对话输入框的插件“粘贴”按钮消失；重新开启恢复文字及图片粘贴。开关由原生保存，网页重载和重新打开面板后继续生效。关闭时停止尚未提交的粘贴传输，保留已有草稿与附件。

试卷页的“选题导入”显示整份试卷，默认全选，可只保留需要的题号。题目详情数据有来源试卷时按第一个来源试卷收集，没有来源时显示该题并放入对应科目的“单题收集”。

默认结构为 `Jifengjincao Bridge / 科目 / 试卷 / 试卷名称 · 第 N 题 / 答案与解析`，新导入不再创建选择题、填空题或解答题分组。已有分组及题卡保持原位置，重复导入仍扫描旧分组查重。新题卡标题使用原来源内容，例如“2014 年考研数学二真题 · 第 19 题”，正文不再追加“来源”行。第一条 Markdown 评论保存题干、题目图片、全部选项及按设置保留的知识点，不保存内部注释。第二条保存原题入口及题卡身份、原卷顺序、来源标记，不创建纯注释评论；历史关闭原题入口的设置不再生效。“导入知识点”仍独立保存，在打开选题框时固定本次设置。已有题卡的标题与来源正文不批量改写。题干保留 Markdown/LaTeX；图片下载并转存为 MN 媒体。答案与解析分别保存在同一子卡的两条 Markdown 评论中；子卡身份注释沿用原结构，放在答案末尾，只有解析时放在解析末尾。在对应学习集打开面板时，会把旧子卡可明确识别的纯身份评论合并进正文，支持撤销。答案子卡默认隐藏在折叠的题卡分支中。

重复导入跳过已有题卡。选择“题目与答案解析”时，只补尚未保存的答案或解析，不更新已有题干、答案、用户评论或手写。网站数据不完整时显示未完成原因，并可重试未完成题目。停止导入保留已完成的卡片。

每道题使用一个撤销分组，整卷导入对应多次撤销。删卡或撤销后再次导入会检查实际卡片，不仅依赖历史映射。

“选题导入”统一显示在网站顶部“AI 组件”左侧，不再悬浮于网页右下角；没有可读题目时禁用。AI 找题只收集最新一轮结果中已经加载的匹配题，排除历史轮次、边界候选与内容暂不可用的题目。题篮详情与公开题篮也支持选题导入，收集当前页面已加载的题目。导入框默认全选，支持“题目／题目＋答案”，逐题保留原试卷与原题号，仍按原卷题卡结构建卡。切换对话或题篮、找题结果变化、题篮题目移除或排序后，旧请求停止，需重新打开选题框。

设置“题目工具”新增“显示导入本题”（默认关闭）与“导入本题位置”（默认子节点，可选同级节点）。开启后在试卷、题目详情、复盘、最新找题结果及题篮详情显示“导入本题”；AI 找题与题篮题号旁的定位入口显示为“定位题目”，仍定位已导入的 MN 题卡。题篮两项工具位于全局题号右侧，分别受已有显示开关控制。先在 MN 选中卡片，再点击“导入本题”，不弹选题框，仅导入题干、选项与题目图片，使用题卡设置中的知识点选项，保留原题入口及身份评论。子节点放到所选卡片下，同级节点插在所选卡片之后；读题期间改选卡片或设置不会改变本次落点。同一父卡下已有该题则跳过，其他父卡已有该题不阻止本次插入。单题操作不改变批量导入的内容选择。

## 真机验收

自动化测试使用模拟 MN 宿主，不能确认系统 WebView、MN Utils 安装版本和 MN 数学渲染器的实际行为。安装后依次检查：

- [试卷 237](https://bbkaoyan.cn/papers/237)：先导入第 1 题，检查题干、选项、答案和复杂公式。
- 导入第 4 / 第 19 题，断网并重启 MN 后查看解析图片。
- 整卷导入 22 题，检查原卷顺序，再导入一次，确认跳过已有题卡。
- 手工增加笔记，再补答案或重试，确认批注保留。
- 在数学与设置页间切换，检查网站浏览位置保留；关闭知识点开关并重新打开面板，确认设置保存，新题卡不含知识点行，再开启后导入另一道新题检查知识点恢复。检查新题卡标题包含试卷和题号、正文没有重复来源；重复导入不会重写旧卡片标题或笔记。
- 确认设置中只有“导入知识点”，新题卡第一条包含完整题干和选项，第二条先显示“查看原题”再保存识别注释。打开已有题卡所属学习集的面板，检查旧注释迁移、原题入口、去重、补答案与定位；撤销能恢复旧结构，用户自改链接和笔记保留。
- 导入时停止、切换网站页面或学习集，检查不会导入到错误位置。
- 使用实际账号检查一份有权限的模拟卷、登录过期及验证提示。
- 在 AI 找题页打开最新结果的“选题导入”，确认默认全选、原卷题号与图片保存；重新找题或切换对话，检查旧预览不能继续导入。
- 开启“显示导入本题”，在 MN 选中卡片，分别验证子节点与同级节点位置、同父重复跳过、另一父卡可再次导入，以及题号旁“定位题目”可以返回对应 MN 题卡。
- 从题卡点击“查看原题”，确认面板关闭时能重新打开，网页定位题目准确；在多个 MN 窗口中确认只打开当前窗口。旧卡片先打开一次面板，确认链接更新后题干、图片、批注及评论顺序保留，撤销可恢复。

不具备网站权限时插件会停止读取；会员内容不能依靠公开真题的测试结果认定可用。复杂数学宏与 HTML 图片可能需要针对样例进一步适配。

## 开发

```sh
npm ci
npm test
npm run check
npm run build
```

默认构建只更新测试包。`npm run build:release` 拒绝 `0.0.0` 和覆盖已有正式包，正式发布须遵循项目规范。构建生成 `src/web-dist/`，网页代码修改 `web/src/`，不要手改生成文件。`BBKaoyanLayout.js` 负责试卷目录布局，`BBKaoyanPage.js` 负责网页导入交互，`BBKaoyanReview.js` 负责各 AI 对话输入框的文字粘贴与图片附件。

源码职责：`BBKaoyanAdapter` 校验题目结构；`BBKaoyanFormat` 整理公式和图文；`BBKaoyanImport` 建卡、补答案与报告；`BBKaoyanTransport` 管理分块传输；`BBKaoyanImportStore` 原子持久化；`JifengjincaoNative` 封装已核实宿主能力；`JifengjincaoSettings` 管理原生设置页与导入配置；`WebPanelController` / `WebAddon` 提供窗口和生命周期。

导入记录在 MN 文稿目录的 `cn.marginnote.jifengjincao-bridge/imports.json`，包含最近 20 个任务和卡片映射，不保存密码、Cookie 或图片 Base64。损坏或不支持的记录文件会保留并提示错误。

目前 109 项自动化测试通过，覆盖页签切换、设置与窄屏布局、第二条原题链接及注释、旧卡迁移与失败恢复、历史关闭配置兼容、去重与补答案，以及定位卡片、多卡选择、跨学习集切换和定位网页校验。试卷 237 的 22 题数据回放通过；试卷 265 的 23 题格式回放及 27 个选项的公式边界修复检查通过。浏览器验证了横屏、竖屏、窄窗口、第二排展开布局、异步题目定位，以及复盘、解题、找题的粘贴入口与合成图片附件。粘贴测试覆盖 WebView 布尔返回值转换、完整网页脚本注入、延迟加载、满额与忙碌提示、切题和输入框替换。公式预览已按用户要求移除，文字摘要和完整原文传输分别验证。原生设置页目前由模拟宿主检查控件创建、布局和事件，需要 MN 真机验收实际显示。安装包已逐文件核对哈希与入口依赖。详见 [实施与验证记录](docs/implementation-validation.md)。

设计及依据：[首版方案](docs/bbkaoyan-to-mn-plan.md)、[MN API 核验](docs/mn-api-research.md)、[导入确认界面优化方案](docs/import-dialog-ui-plan.md)。
